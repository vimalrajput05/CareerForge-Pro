# 🚀 CareerForge Pro

A modern Resume Builder web application built using React, Vite, and Tailwind CSS. This project helps users create professional resumes, check ATS scores, and generate cover letters easily.

---

## 📂 Project Structure

CareerForge-Pro/
│
├── frontend/        # React Frontend
├── backend/         # Backend (to be developed)

---

## 🛠️ Tech Stack

- React.js
- Vite
- Tailwind CSS
- JavaScript

---

## ⚙️ Setup Instructions

Follow these steps to run the project locally:

```bash
# Clone the repository
git clone https://github.com/vimalrajput05/CareerForge-Pro.git

# Go to project folder
cd CareerForge-Pro

# Open in VS Code
code .

# Go to frontend
cd frontend

# Install dependencies
npm install

# Run project
npm run dev
